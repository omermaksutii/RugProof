What's in the box

33 slash commands

From /audit and /quick-scan to /exploit, /audit-live, /replay-incident, /invariant, and /card. Every command is real prompt content backed by Foundry, Anvil, and the Etherscan family.

31 vulnerability skills

Auto-loaded detection patterns. Reentrancy (incl. read-only), oracle manipulation, flash-loan attacks, MEV, signature replay, ERC-4337 AA, cross-chain messaging, ERC-7683 intents, EigenLayer restaking, ERC-4626 inflation, and 21 more.

19 specialist agents

An attacker red team and defender blue team. Plus AMM, lending, staking, bridge, governance, vault, NFT, AA, cross-chain messaging, restaking, and intents specialists.

9 MCP servers

block-explorer · forge-runner · hardhat-runner · anvil · tenderly · c4-history · sherlock-history · gas-tracker · token-metadata. Real chain I/O, not mocks.

Working PoCs

/exploit <finding> writes a Foundry test that proves the bug — and re-runs until it passes. No theoretical findings; every Critical comes with a smoking gun.

Shareable audit cards

Every audit produces a 1200×1200 PNG card with the grade, severity counts, and top finding. Built for tweets, threads, and PR comments.

GitHub Action

Drop uses: omermaksutii/RugProof-action@v1 into a workflow. Audits every PR, posts findings as a sticky comment, blocks merge on Critical.

Soulbound NFT certificates

Optional: mint your audit grade as a soulbound NFT on Berachain. Permanent, on-chain proof of audit. Cosmetic — but undeniable.

Install

# In Claude Code:
/plugin marketplace add omermaksutii/RugProof
/plugin install rugproof
/rugproof-init                # 60-second setup
/audit examples/VulnerableVault.sol   # see it work on a planted-vuln demo

Local dev:

git clone https://github.com/omermaksutii/RugProof ~/.claude/plugins/rugproof
cd ~/.claude/plugins/rugproof/mcp && npm install && npm run build

GitHub Action

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: omermaksutii/RugProof-action@v1
        with:
          anthropic-api-key: ${{ secrets.ANTHROPIC_API_KEY }}
          threshold: high
